# أبديت كارد — بطاقتك تفتح عالمك

تجربة عربية RTL لاستكشاف خدمات أبديت كارد وتجهيز الاستفسارات عبر واتساب. تتضمن مشهد بطاقات تفاعليًا، كتالوج الخدمات الفعلي، البحث والتصنيف، تفاصيل الخدمة، وطلبات الأفراد والجملة.

## التشغيل

المتطلبات: Node.js 24 وnpm.

من جذر المستودع:

```sh
npm install
npm run dev
```

أو لتشغيل التطبيق مباشرة:

```sh
cd experience
npm install
npm run dev
```

## البناء والفحص

```sh
npm run build
npm test
npm run test:e2e --prefix experience
```

قبل أول فحص متصفح: `cd experience` ثم `npx playwright install chromium`.

الناتج: `experience/dist`. إعداد Vercel في هذا الفرع يشغّل هذه النسخة.
لمعاينة الناتج: `npm run preview --prefix experience`.

## المكونات

- React + Vite، وCSS مخصص للحركة والتجاوب.
- بيانات الخدمات مستوردة من `src/data` في المستودع، دون نسخ الكتالوج.
- الصور والخطوط محلية من `src/assets`، والشعار من `brand/web`.
- حركات قصيرة عند التفاعل، دون حلقة رسم مستمرة أو تغيير تمرير الهاتف.
- رابط مباشر للخدمة: `/#service/games/pubg-mobile`.
- البحث يدعم العربية والإنجليزية وتوحيد الهمزات والتشكيل.
- الطلب ينتقل لواتساب برسالة جاهزة؛ لا ينفّذ شراءً أو دفعًا داخل الموقع.
- فشل JavaScript يبقي وصف الخدمات وروابط الكتالوج والتواصل في HTML.
- نسخة تقليل الحركة متاحة تلقائيًا حسب إعدادات الجهاز.
- منع الفهرسة مقصود للمعاينة؛ يراجع قبل تحويلها إلى النسخة الرسمية.

## التحقق

`tests/`: سلامة الكتالوج، وجود الصور، البحث، ترميز الرسالة، وروابط الخدمات.
`e2e/`: عروض 320/360/390/768/1280، بحث، تفاصيل، رجوع وتقدم، لوحة مفاتيح، محاكاة اللمس، تقليل الحركة وغياب JavaScript.

النتائج الفعلية تظهر في GitHub Actions إن كان مسموحًا بتشغيله. وجود الاختبارات لا يعني أنها نجحت. فحص هاتف حقيقي وقياس الأداء الميداني والتكبير الفعلي 200% يحتاج تنفيذًا منفصلًا.
