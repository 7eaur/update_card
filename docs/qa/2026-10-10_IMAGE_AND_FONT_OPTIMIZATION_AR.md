# تدقيق وتحسين الصور والخط — أبديت كارد

**التاريخ:** 2026-10-10
**النطاق:** جميع الصور المرتبطة فعليًا بصفحات الموقع، مع تركيز تفصيلي على صور بطاقات الخدمات، وطريقة تحميل خط Cairo.

## 1. النتيجة التنفيذية

- تم فحص مراجع الصور في الصفحات المولدة والتحقق من وجود الملفات وعدم وجود صور خدمات غير مستخدمة ضمن حزمة النشر.
- بقيت الصور الخفيفة كما هي؛ إعادة ضغطها لن تمنح توفيرًا مؤثرًا وقد تخفض الجودة دون داعٍ.
- أعيد ترميز 25 صورة ثقيلة فقط إلى AVIF بمقاس 512×512 وإعداد محافظ.
- تحقق Decode لكل الصور المعدلة بنجاح.
- نتيجة مقارنة كل صورة بالمصدر كانت `SSIM >= 0.95`، وهي بوابة الجودة المعتمدة في هذه الدفعة.
- استضيف خط Cairo محليًا بدل CSS خارجي من Google Fonts، مع preload للجزء العربي و`font-display: swap`.

## 3. معالجة تأخر ظهور الخط

الوضع السابق كان يحتاج طلب CSS من `fonts.googleapis.com` ثم طلب ملف الخط من `fonts.gstatic.com`. على شبكة بطيئة قد يظهر الخط الاحتياطي أولًا ثم يتبدل إلى Cairo.

التنفيذ الجديد:

1. تخزين نسختي Cairo العربية واللاتينية محليًا بصيغة WOFF2.
2. تحميل الملف العربي مسبقًا من نفس نطاق الموقع.
3. تعريف الخط كمتغير للأوزان 400–800 بدل عدة ملفات مستقلة.
4. إبقاء `font-display: swap` حتى لا يتوقف ظهور النص إذا تعذر الخط.
5. إضافة فحص بناء يمنع عودة أي مرجع خارجي إلى Google Fonts ويتأكد من وجود ملفات الخط والترخيص.

## 4. التحقق

- `npm run build`: نجح، وبُنيت 14 صفحة ثابتة.
- `npm run check`: نجح، وشمل 101 مرجعًا محليًا و66 صورة خدمة و8 مسارات استفسار.
- `identify` لجميع صور الألعاب والتسوق المعدلة: نجح Decode.
- `fc-scan` لملفي Cairo: تعرف على العائلة والأوزان المتغيرة بنجاح.
- `git diff --check`: بلا أخطاء مسافات أو تنسيق.

## 5. حدود القياس

هذا التدقيق يثبت خفض حجم الملفات وإزالة الاتصال الخارجي للخط وسلامة البناء. قياس LCP/INP/CLS الحقيقي يحتاج بيانات مستخدمين أو Lighthouse في ظروف شبكة وجهاز ثابتة؛ لذلك لا تُذكر درجة سرعة رقمية غير مقاسة هنا.
