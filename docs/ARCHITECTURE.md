# بنية مشروع UPDATE CARD

## نظرة عامة

المشروع موقع عربي ثابت متعدد الصفحات. تُبنى الصفحات من بيانات ومكونات JavaScript داخل `src/`، ثم يحولها سكربت البناء إلى ملفات جاهزة للنشر داخل `dist/`.

```mermaid
flowchart LR
  A[بيانات ومكونات src] --> B[scripts/build.mjs]
  B --> C[ملفات dist]
  C --> D[scripts/check.mjs]
  D --> E[Vercel]
```

## طبقات المشروع

| المسار | المسؤولية |
|---|---|
| `src/config/` | معلومات العلامة، النطاق وبيانات التواصل |
| `src/data/` | فئات الخدمات، الخدمات الفرعية، الأسئلة ورسائل الطلب |
| `src/components/` | الهيدر، الفوتر، البطاقات والعناصر المشتركة |
| `src/pages/` | محتوى وتكوين كل صفحة |
| `src/templates/` | هيكل HTML العام وبيانات SEO المشتركة |
| `src/client/` | التفاعلات، التنقل، المقدمة ونموذج التواصل |
| `src/styles/` | الأساس، التخطيط، المكونات، الحركة والتجاوب |
| `src/assets/` | الصور المحسنة، الخطوط والوسائط |
| `brand/` | المصدر الأصلي للشعار واشتقاقاته المعتمدة |
| `scripts/` | توليد الموقع، التحقق وخادم التطوير |

## مسار البناء

1. يقرأ `scripts/build.mjs` بيانات الموقع والمكونات والصفحات.
2. ينشئ صفحات HTML ومسارات الخدمات داخل `dist/`.
3. يجمع ملفات CSS وينسخ JavaScript والأصول والخطوط والشعار.
4. ينشئ `sitemap.xml` و`robots.txt` وملفات PWA المطلوبة.
5. يفحص `scripts/check.mjs` الصفحات والروابط والأصول ومسارات واتساب وضوابط الأداء الأساسية.

## النشر

- الفرع الإنتاجي الوحيد: `main`.
- المنصة: Vercel.
- أمر البناء: `npm run build`.
- مجلد النشر: `dist`.
- النطاق الأساسي: `https://updatecard.net`.

## الضمانات الآلية

Workflow باسم `Site CI` يتحقق من:

- نجاح بناء جميع الصفحات.
- صحة الروابط والمراجع المحلية.
- سلامة صور AVIF وإمكانية فكها.
- ميزانيات CSS وJavaScript وHTML والوسائط.
- لقطات بصرية للهاتف وسطح المكتب.
- وجود إعدادات SEO والوصول ومسارات طلب الخدمات.

## قواعد الصيانة

- تجرى التغييرات في فرع قصير العمر ثم Pull Request إلى `main`.
- لا تُحفظ ملفات `dist/` في Git لأنها ناتج بناء.
- تُضاف الخدمات من طبقة البيانات بدل تكرار HTML.
- تُستخدم الأصول المحسنة داخل `src/assets/`، وتبقى مصادر الهوية داخل `brand/`.
- يجب تشغيل `npm run build` و`npm run check` قبل الدمج.
