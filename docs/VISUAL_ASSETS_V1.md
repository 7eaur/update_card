## Rules

- Use the hero image eagerly only on the Home page.
- All below-the-fold visuals use native lazy loading.
- Keep intrinsic width/height in markup to prevent CLS.
- Generated visual artwork is supportive; important copy remains real HTML text.
- Do not present third-party platform marks as an official partnership unless separately verified.
