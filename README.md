## المميزات

- مشهد بطاقات تفاعلي بثلاثة عوالم: الألعاب، البطاقات والاشتراكات.
- كتالوج الخدمات الفعلي مع البحث بالعربية والإنجليزية والتصنيف.
- تفاصيل كل خدمة برابط مباشر وطلب مخصص للأفراد والجملة.
- رسالة واتساب جاهزة تتضمن الخدمة والمنطقة والتفاصيل.
- تصميم متجاوب وخطوط وصور محلية ونسخة لتقليل الحركة.
- أقسام لطريقة الطلب والجملة والأسئلة الشائعة والتواصل.

## التشغيل

يتطلب Node.js 24 وnpm.

```sh
npm install
npm run dev
```

```sh
npm run build
npm test
```

لبناء فحص المتصفح، من مجلد `experience` شغّل `npx playwright install chromium`، ثم من الجذر `npm run test:e2e`.

## هيكل المشروع

| المسار | المحتوى |
| --- | --- |
| `experience/src` | واجهة React وقواعد الحركة والتنسيق |
| `experience/tests` | فحص الكتالوج والبحث ورسائل الطلب |
| `experience/e2e` | اختبارات المتصفح والتجاوب |
| `src/data` | بيانات الخدمات الأصلية |
| `src/assets` | الصور والخطوط المحلية |
| `brand` | الشعار وأصول الهوية |
