# قواعد ومراجع UPDATE CARD

هذا الفرع مخصص لقواعد الصيانة والهوية وأدوات التحقق التي فُصلت عن فرع الموقع `main` بطلب المالك. ليس نسخة موقع للنشر، ولا يُدمج بالكامل في `main`.

| الملف | المحتوى |
|---|---|
| `rules/ARCHITECTURE.md` | طبقات المشروع وقواعد الصيانة السابقة |
| `rules/BRAND.md` | مصدر الشعار وقواعد استخدام الهوية |
| `checks/check.mjs` | أداة التحقق الأصلية، للرجوع إليها عند الحاجة |
| `workflows/site-ci.yml` | فحوص CI والبناء والوسائط والأداء السابقة |

المصادر محفوظة دون تغيير من الإصدار المنشور `179de8200e5ea0a480e159f37de14e8bd6bf8f6a` بتاريخ الفصل 2026-11-13. لم توجد ملفات AGENTS أو حزم SKILL في أي من رؤوس الفروع الـ55 وقت الفحص، لذلك لم تُنشأ مهارات بديلة أو قواعد جديدة.

أدوات `checks/` مراجع غير مهيأة للتشغيل من هذا الفرع؛ تعتمد على شجرة مشروع الموقع ومساراتها الأصلية، وبعضها يعتمد على وثائق فُصلت. توثيق المشروع الحالي وتشغيله موجودان في README على `main`.
