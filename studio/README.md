# Digital Arena — Update Card
Independent immersive Arabic RTL gaming storefront redesign. Source: 7eaur/update_card (contact and service names only). Research: updatecard.net, level-up.gg/ar, webflow.com/blog/interactive-website, shopify.com/blog/how-to-make-an-interactive-website.

## Visual language
Premium dark gaming arena. Brand-inspired indigo, deep plum and crimson, accented by cyan, motion and neon-lit product-card compositions. No copied graphics or layouts.

## Delivered prototype
- Searchable and filterable services with no invented prices or stock
- Accessible request drawer, mobile menu, keyboard search, WhatsApp request handoff
- Hero pointer parallax only on desktops, native mobile scroll, reduced-motion controls
- Categories, process, wholesale, custom requests, FAQs and footer
- Original vector hero art and generative visual reference
- Isolated studio/ Vite root and dedicated Vercel project

## Product constraints
This is a front-end lead-generation storefront, not a real checkout. Real e-commerce still needs validated provider integrations, product pricing and stock, payments, backend order states, secure delivery, admin, support and webhooks. No passwords, OTPs or sensitive payment data via WhatsApp.

## Local development
cd studio
npm install
npm run dev
npm run build
