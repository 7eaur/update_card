# UPDATE CARD — faithful original logo assets

This package deliberately preserves the supplied logo artwork exactly. The previous reconstructed UC symbol, replacement typography, monochrome variants, and fabricated app/favicons were removed because they were not the supplied logo.

## Use these files

| File | Use |
| --- | --- |
| `logo/original/png/update-card-original-wordmark-on-white.png` | Canonical logo; exact cropped pixels from the supplied original |
| `logo/original/png/update-card-original-wordmark-transparent.png` | Same original wordmark with only the white source background made transparent; light surfaces only |
| `logo/compact/png/update-card-original-compact-on-white.png` | Compact lockup exactly as it appears inside the supplied image |
| `web/logo-horizontal.png` | Website use on a white container |

## Source limitation

The supplied source is a raster JPEG, not an editable vector master. A clean SVG, monochrome redraw, standalone UC icon, high-resolution app icon, or favicon cannot be truthfully generated from it without changing the original. They are intentionally **not** included.

For a complete vector-ready package, provide the original AI, SVG, EPS, PDF, or a high-resolution transparent PNG from the logo designer. Until then, use the canonical on-white PNG without recolouring, reshaping, or rearranging it.
